# UMK3 Android — Sega Genesis workspace

## تنزيل النسخة الشخصية 0.9.1

**[صفحة الإصدار وAPK المباشر ضمن Assets](https://github.com/midoali250/umk3-android/releases/tag/v0.9.1-umk3)**

نسخة `UMK3-Android-0.7.apk` تتضمن اللعبة التي وفرها مالك المستودع وتفتحها تلقائيًا. هذا استثناء شخصي من بناء المصدر العام الذي لا يضمّن ألعابًا افتراضيًا. المستودع خاص؛ سجّل الدخول بحساب يملك صلاحية الوصول لتنزيل الأصل. راجع [سجل التحقق](docs/VERIFICATION.md) و[وظايف الغش](docs/CHEATS.md) قبل اعتبار أي فحص ناجحًا.

تطبيق أندرويد يشغّل ألعاب **Sega Genesis / Mega Drive** عبر محرك Genesis Plus GX، مع عرض SurfaceView أصلي وخيط رسم مستقل، ومسار Canvas احتياطي، وتحكم لمسي متعدد النقاط، وإعدادات قابلة للتخصيص، وحفظ SRAM.

> **البناء العام مقابل النسخة الشخصية:** بناء المصدر افتراضيًا لا يضمّن لعبة؛ يستورد المستخدم ملفًا يملك حق استخدامه. APK الشخصي 0.9 يضمّن ملف UMK3 المرفوع، ولا يُرفع ملف اللعبة إلى تاريخ Git. المحرك مدمج تحت ترخيص Genesis Plus GX غير التجاري؛ راجع `THIRD_PARTY_NOTICES.txt` قبل أي توزيع.

## ما الذي يعمل الآن؟

- محاكاة Genesis فعلية عبر Genesis Plus GX، مع صوت وفيديو وSRAM.
- ثلاثة أوضاع للصورة: البكسل الأصلي، تنعيم Bilinear، و**Smooth+** الافتراضي. مسار SurfaceView يستخدم ترشيح Bitmap عند التكبير؛ المسار الاحتياطي يضيف تمرير تكبير مسبق 2×. لا يعتمد العرض على shaders مخصصة.
- عرض الصورة كاملة بدون قص: ملاءمة Fit مع أشرطة سوداء عند الحاجة، أو ملء الشاشة بالتمدد، مع **زر ترس دائم أعلى يسار الشاشة** يفتح قائمة جانبية للإعدادات بدل الاعتماد على زر الرجوع، ومراقب يبدّل تلقائيًا لمسار العرض الاحتياطي إذا اكتشف سطحًا أسود.
- **عصا اتجاهات حرة** بدل صليب الأسهم: القرص كله وحدة واحدة، الاتجاه يُقاس من مركزه في ثماني قطاعات مع منطقة ميتة، والمقبض يتحرك مع الإصبع. لذلك تعمل الزوايا (قفز للخلف، قفز للأمام، كنس بزاوية) وترسل المحورين معًا — الصليب القديم كان يختار محورًا واحدًا عند التعادل فلم تعمل الزوايا.
- يد سيجا **6 أزرار**: العصا + X/Y/Z + A/B/C + START، متصلة فعليًا بمدخلات المحرك، مع دعم الضغط المتزامن (مثل يمين + B). يمكن التبديل إلى 3 أزرار من الإعدادات.
- **زر FINISH (نجمة)**: ضغطة واحدة تفتح قائمة نهائيات وحركات المقاتل — قتلتان، قتلة الساحة، صداقة، طفولة، تحوّل، وكل الحركات الخاصة (216 إدخالًا لـ23 مقاتلًا)، كل منها بضغطة واحدة تنفّذ الإدخال كاملًا. الضغط المطول يعيد تنفيذ آخر حركة فورًا. اللعبة تظل تعمل خلف القائمة حتى تدخل القتلة أثناء «FINISH HIM».
- الإدخالات مأخوذة من قوائم الحركات المجتمعية (mortalkombatwarehouse) ومولّدة بـ`tools/generate_moves.py`، مع خيار عكس الاتجاهات عندما تكون واقفًا على اليمين. التفاصيل في [docs/MOVES.md](docs/MOVES.md).
- **وظايف الغش داخل اللعبة**: من قائمة الترس — طاقة لا نهائية (الشريط ما ينقصش ولا إطار، مقفول عند الكتابة في الذاكرة)، جري لا نهائي، تثبيت الوقت على 99، وضربة واحدة تُسقط الخصم. تُكتب في ذاكرة العمل أثناء المباراة الجارية فقط (لا تلمس القوائم)، وتُحفظ بين الجلسات، ويظهر شعار «غش» على الشاشة عند تفعيلها. العناوين مقيسة على النسخة الفعلية ومُثبتة باختبارين آليين — [docs/CHEATS.md](docs/CHEATS.md).
- تحسينات أداء: بناء native بـ `-O3`، قراءة الإدخال كـ bitmask، إعادة استخدام مخازن الإطارات، حفظ SRAM خارج خيط المحاكاة، وتخطي إطارات تلقائي اختياري للأجهزة البطيئة.
- تحريك مجموعات التحكم وتغيير الحجم والشفافية من الإعدادات، وحفظLayout تلقائيًا.
- استيراد ROM عبر Android Storage Access Framework، وإيقاف/استئناف، وإعادة ضبط اللعبة.
- حفظ تلقائي لـ SRAM لكل لعبة، واستعادته عند فتحها مجددًا.
- إشعارات التراخيص داخل التطبيق.

## بناء APK بأمر واحد

المتطلبات: **JDK 17**، **Android SDK Platform 35**، **Build Tools 35.0.0**، **NDK 27.0.12077973**، و**CMake 3.22.1**. اضبط `ANDROID_HOME` أو `local.properties`. لا تحتاج إلى Gradle عالميًا.

Linux / macOS:

```bash
./scripts/build-apk.sh debug
```

Windows:

```bat
scripts\build-apk.bat debug
```

أو مباشرة:

```bash
./gradlew :android:exportDebugApk
```

**الناتج القابل للتثبيت:**

```text
artifacts/apk/sega-android-debug.apk
```

التثبيت على جهاز متصل:

```bash
adb install -r artifacts/apk/sega-android-debug.apk
```

النسخة موقّعة بمفتاح debug. التفاصيل في **[دليل البناء](docs/BUILD_APK.md)**، ونتائج الاختبار الفعلية في **[سجل التحقق](docs/VERIFICATION.md)**.

## هيكل المشروع

```text
atari-android-agent/
├── android/                     # تطبيق Android: Activity، العرض، التحكم، الإعدادات
├── core/                        # JNI + Genesis Plus GX + منطق التحكم والاختبارات
│   └── src/main/cpp/genesis-plus-gx/
├── roms/                        # ملفات مصرّح بتوزيعها فقط؛ لا تُضمَّن افتراضيًا
├── scripts/                     # بناء وتصدير APK
├── docs/                        # البناء والتحقق
├── tests/                       # اختبار native smoke على المضيف
├── .github/workflows/           # بناء debug وإصدار release موقّع يدوي
├── THIRD_PARTY_NOTICES.txt      # تراخيص المحرك والمكونات
└── gradle/wrapper/              # Gradle 8.11.1 مثبت البصمة
```

## أوامر التحقق

```bash
./gradlew :core:test :android:testDebugUnitTest :android:lintDebug
./gradlew :android:exportDebugApk
```

اختبار اللمس الفعلي على محاكي (يتطلب ROM محليًا ولا يوزّعها):

```bash
adb install -r android/build/outputs/apk/debug/sega-android-debug.apk
adb install -r android/build/outputs/apk/androidTest/debug/sega-android-debug-androidTest.apk
adb push /path/to/game.gen /data/local/tmp/sega-test/game.gen
adb shell am instrument -w -r \
  -e class com.midoali.atari.ControlsInstrumentedTest \
  -e rom /data/local/tmp/sega-test/game.gen \
  com.midoali.atari.debug.test/androidx.test.runner.AndroidJUnitRunner
```

أضف `-e screenshots true` لالتقاط صور داخل التطبيق أثناء الاختبار.

## الأمان وحقوق الألعاب

- لا تضع كلمات المرور أو رموز الوصول أو مفاتيح التوقيع داخل Git.
- لا تُضمَّن ROMs إلا عند تمرير `--bundle-roms` أو `-PbundleRoms=true`، وبامتدادات `.a26/.bin/.a78/.md/.gen/.smd` فقط. استخدم فقط ملفات تملك حق استخدامها وتوزيعها.
- Genesis Plus GX ومكوناته لها تراخيص محددة؛ التوزيع التجاري غير مسموح به وفق ترخيص المحرك. راجع الإشعارات المرفقة.
- مفاتيح debug تختلف بين الأجهزة/تشغيلات CI؛ التحديث فوق توقيع مختلف قد يتطلب حذف النسخة القديمة. احفظ بياناتك أولًا.
